# DevOPSQuiz

Une appli console Java qui fait passer un quiz sur Linux/Git/Jenkins/Docker/DevOps, avec une chaîne CI/CD complète autour.

Fonctionnalités : 
    F1 : Création de 20  question sur les themes : Linux, Git/GitHub, Jenkins, Docker et les principes DevOps. Chaque question possede 4 choix et une bonne réponse

    F2 : Permet au joueur de choisir une catégorie particulière ou un quiz général qui lui demande de repondre a 10 questions aléatoirement

    F3 : L'application accorde au joueur une note sur 10, un pourcentage de réussite et un message de fin adapté

    F4 : L'application possede un fichier de sauvegarde, qui conserve, le pseudonyme du joueur, son score et la date de la partie

    F5 : Intégration d'une gestion des saisie incorrecte sans arrêter l'application

Environnement technique : 

    Développer sur Linux ubuntu 26.04 et MacOs 
    Java version : openjdk version "25.0.5.1"
